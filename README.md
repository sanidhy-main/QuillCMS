# QuillCMS

A full-stack blog Content Management System built with **Java, Spring Boot, and PostgreSQL**.

QuillCMS is a backend-focused project designed to provide the core functionality of a modern blogging platform, including user authentication, authorization, post management, comments, profiles, and social interactions.

## Tech Stack

* **Java**
* **Spring Boot**
* **Spring Data JPA**
* **Spring Security**
* **PostgreSQL**
* **Gradle**

## Features

### User Management

* User registration
* User authentication
* Authorization and role-based access
* User profiles

### Content Management

* Create, read, update, and delete posts
* Post ownership and authorization
* Comments and interactions

### Social Features

* Follow users
* Block users
* User interactions

> More features will be added as the project develops.

## Project Goals

The primary goal of QuillCMS is to build a complete, production-oriented backend while gaining practical experience with:

* REST API design
* Spring Boot application architecture
* Database design and relational data modelling
* Authentication and authorization
* Secure backend development
* JPA and Hibernate
* PostgreSQL
* Building and maintaining a larger software project

## Development

QuillCMS is being developed incrementally, with the focus initially being on building a reliable and functional backend before expanding into frontend and platform-level features.
